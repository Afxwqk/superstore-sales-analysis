# 📊 Superstore Sales Performance Analysis

## Overview
Built an interactive Tableau dashboard to analyze sales and profitability across regions and product categories.

## Key Insights
- Some high-revenue categories are not profitable
- West region performs best overall
- Sales increase toward end of year
